# Contributing

## Branches

- `main`: siempre desplegable.
- `feat/<id>-descripcion`
- `fix/<id>-descripcion`
- `chore/<descripcion>`

## Commits

Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `perf:`, `build:`, `ci:`, `chore:`.

## Pull Request

Cada PR debe indicar: story/spec, cambios de datos/contrato, riesgos, tests ejecutados, capturas para UI y plan de rollback cuando aplique.

Usar `.github/pull_request_template.md`.
