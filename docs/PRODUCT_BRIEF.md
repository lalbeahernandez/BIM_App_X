# Product brief

## Visión

Crear un sistema operativo de Project Controls BIM que conecte modelo, cantidades, coste, planificación, productividad, progreso, calidad y colaboración en un mismo grafo de información verificable.

## Usuarios principales

BIM Manager, Planner, Quantity Surveyor/Cost Manager, Project Controls Manager, Site Manager, QA/QC, Design Manager, Owner/PMO, Admin y Viewer.

## MUST — MVP

- organizaciones/proyectos/RBAC básico;
- carga y versionado IFC;
- índice de elementos y propiedades esenciales;
- viewer federado con selección, isolate, filtros, clipping y color rules;
- mapping Element <-> BOQ y Element <-> Activity;
- BOQ con QTY/unit/rate/amount y revisiones;
- WBS/Gantt con FS/SS/FF/SF, lag, calendarios y baseline;
- 4D por data date;
- progress records históricos;
- issues + viewpoints básicos;
- audit trail, API y export CSV/XLSX.

## SHOULD — Beta

IDS, BCF import/export/API, model diff, productivity/crews, EVM, cash flow, QA/QC, dashboards, GIS básico, SSO/OIDC, webhooks e integraciones de scheduling.

## COULD — Enterprise/advanced

clash orchestration, remapeo probabilístico cuando cambia GlobalId, rule engine visual, carbon/LCA, digital twin/IoT, offline field app, optimization/scenario engine, AI copilot con RAG controlado y approvals.
